# Stafford Reservoir

Western Chin Coulee basin east of Lethbridge (kite group: Stafford Lake).

OSM maps this water as part of the Chin Lakes multipolygon. Chop uses the western outer rings (`way/202592593` + `way/809860353`, island `way/809860352`) so it stays separate from the AGS **Chin Lakes** DEM further east.

Depth: synthetic (max 20.0 m).
